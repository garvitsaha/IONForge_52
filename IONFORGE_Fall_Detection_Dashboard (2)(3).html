Offline-first behavior

The armband does not require a SIM. When Wi-Fi is unavailable, fall events are buffered on the device. Once Wi-Fi returns, the ESP32 sends the queued events to the backend, which then triggers caregiver notifications.

Recommended flow

Fall → Local storage → Wi-Fi reconnect → Backend sync → SMS + WhatsApp → Caregiver acknowledgement
