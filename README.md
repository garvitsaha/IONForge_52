IonForge is a smart IoT-based fall detection and caregiver monitoring system that uses ESP32, MPU6050 motion sensing, GPS, local alerts, and a web dashboard to detect and monitor fall events. The system creates a unique fall event, sends event and location data to a Node.js backend, stores the information, and displays it through a React dashboard for caregiver monitoring.
